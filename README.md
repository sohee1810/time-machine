# 🕰️ 타임머신 수리 미션 (Lesson 8 · A Butterfly That Changed the Future)

중2 영어(동아·윤) 8과 본문(139~144쪽)을 6개 스테이션에서 읽고 푸는 방탈출형 웹앱입니다.
Google Apps Script와 Google 스프레드시트로 동작합니다.

## 파일 구성 (`gas` 폴더)

| 파일 | Apps Script에서 만들 이름 | 내용 |
|---|---|---|
| `Code.gs` | 스크립트 `Code` | 서버 코드 (스테이션·정답, 채점, 저장, 교사 기능) |
| `Index.html` | HTML `Index` | 학생 화면 |
| `Teacher.html` | HTML `Teacher` | 교사 대시보드 |

> `preview` 폴더는 PC에서 미리 보기 위한 도구예요. Apps Script에 올리지 않아요.

## 설치 방법

1. 구글 드라이브에서 **새 스프레드시트**를 만들어요. 이름 예: `타임머신 수리 미션 기록`
2. 메뉴에서 **확장 프로그램 → Apps Script**를 열어요.
3. 기본 파일 `Code.gs`의 내용을 모두 지우고 `Code.gs` 내용을 붙여 넣어요.
4. **＋ → HTML**로 `Index`와 `Teacher`를 만들고 각각 붙여 넣어요. (`.html`은 자동으로 붙어요)
5. 저장(💾)한 뒤 위쪽 함수 선택에서 **`setup`**을 고르고 **실행**을 눌러요. 처음에는 권한 승인 창이 떠요.
   → 스프레드시트에 `Teams`, `Log`, `Recordings` 시트가 생겨요.
   - 녹음 저장 때문에 **구글 드라이브 권한**도 함께 물어봐요. 허용해 주세요.
   - 예전 버전을 쓰다가 바꾼 경우에도 `setup`을 한 번 더 실행해요 (시트 머리글이 새 열로 바뀌어요).
6. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** (없으면 "(학교 도메인) 내 모든 사용자")
7. 나온 **웹 앱 URL**을 사용해요.
   - 학생용: `https://script.google.com/.../exec`
   - 교사용: 같은 주소 끝에 **`?page=teacher`** 를 붙여요. 비밀번호는 `goldmedal`이에요 (`Code.gs` 맨 위).

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**를 해야 학생 화면에 반영돼요.

## 수업 준비

- 교실에 **스테이션 1~6**을 만들고, 교과서 139~144쪽 본문을 한 쪽씩 종이로 붙여요. (앱에는 삽화가 없어요)
  - 선택: 141쪽 삽화 아래쪽에 파란 나비가 있어서, 종이 지문에 "삽화 속 숨은 나비 찾기" 보너스 단서로 쓸 수 있어요.
  - 학생 화면에도 본문이 한 문장씩 나와요 (소리 내어 읽기). 문장은 교사 화면 **📄 읽기 문장** 탭에서 고칠 수 있어요.
- 모둠마다 **모둠 코드**를 알려 줘요. 예: `3-2` (3반 2모둠). 같은 코드로 다시 들어오면 이어서 해요.

## 학생 흐름

1. 모둠 코드 → 모둠 이름 → **모둠원 이름**(2~4명, 읽는 순서) 입력 → 🚀 탑승
   - 이미 있는 모둠 코드를 넣으면 모둠 이름과 모둠원이 나오고 "우리 모둠이 맞나요?"를 확인한 뒤 이어서 해요.
2. 스테이션 1 → 6 순서대로
   - **🎙 소리 내어 읽기**: 본문이 한 문장씩 나오고, 모둠원이 이름 순서대로 돌아가며 한 문장씩 녹음해요.
     녹음 → 다시 들어 보기 → ✅ 인증 보내기. 문장 길이에 비해 너무 짧으면(단어당 0.3초, 최소 1.5초) 보낼 수 없어요.
     읽는 순서는 스테이션이 바뀌어도 이어져요. 다 읽어야 미션 2개가 열려요.
   - **미션 2개**를 풀어요. 미션 화면의 "📖 본문 다시 보기"로 본문을 다시 볼 수 있어요.
   - **📝 정리** (미션 뒤, 열쇠 받기 전)
     - ① 함께 요약하기: 그 구역 한 줄 요약의 빈칸 2개를 단어 카드로 채워요. 틀리면 오답 대기 시간이 걸려요.
       맞히면 완성된 요약과 우리말 해석이 나와요.
     - ② 1인 1문제: 모둠원이 이름 순서대로 **한 명씩 다른 O/X 문제**를 혼자 풀어요.
       틀리면 정답과 **근거 문장**이 나오고, 4초 뒤 같은 사람이 다른 문제로 다시 풀어요 (대기 시간 없음).
     - 모둠원 모두 맞히면 🔑 열쇠를 받아요. 구역당 1~2분 정도 걸려요.
   - 끝낸 스테이션은 위쪽 번호를 눌러 다시 볼 수 있어요.
   - 🔑 열쇠 창이 뜨고 **4초 뒤 자동으로** 다음 구역으로 넘어가요 (선생님이 열어 줄 필요 없음).
   - 5·6번을 끝내면 열쇠 창에 💬 Think 토론 질문이 함께 나오고 12초 동안 보여요. 마무리 화면에도 다시 나와요.
3. 🔐 최종 암호: 열쇠 단어 6개를 이야기 순서대로 놓기 (카드로 놓거나 직접 입력)
   - 이 화면에서는 위쪽 열쇠 슬롯이 🔑로 가려져요 (슬롯 순서가 곧 정답이라서).
   - 틀리면 힌트: "이야기가 일어난 순서를 떠올려 봐!"
4. **현재로 복귀!** → 간판이 `NAIM ANY YEER EN THE PAST.`로 바뀌는 반전 → 마무리 토론 "작은 나비 한 마리가 왜 미래를 바꿨을까?"

| 스테이션 | 미션 1 | 미션 2 | 열쇠 단어 |
|---|---|---|---|
| 1 (139쪽) | Who was on the news? → Mr. Keith | What did Eckels always want to see? → dinosaur | dinosaur |
| 2 (140쪽) | Where did the time machine arrive? → (in) the jungle of 60 million years ago | Travis의 규칙 O/X 3개 → X O O | path |
| 3 (141쪽) | What was the jungle covered in? → fog | "I don't want you to do anything foolish" → Travis | fog |
| 4 (142쪽) | What appeared one hundred meters away? → a T. rex | 사건 카드 4장 순서 배열 | T. rex |
| 5 (143쪽) | What was on his shoes? → a little mud | "You put all of us in danger" → Travis | mud |
| 6 (144쪽) | What did Eckels find…? → a small dead butterfly | Everything looked the same, except ___ → the big sign on the wall | butterfly |

## 채점 규칙

- 영어 답은 **대소문자·마침표·쉼표 무시**, 맨 앞 `a / an / the` 무시, `T-rex`·`T. rex`·`T rex` 같은 표기는 같게 봐요.
- 그 밖에는 **허용 답안 목록**과 정확히 같아야 정답이에요. 교사 화면 **✅ 허용 답안** 탭에서 한 줄에 하나씩 추가·수정해요.
- 오답이면 그 모둠 전체가 **대기 시간**(기본 30초) 동안 제출할 수 없어요.
- 최종 암호는 글자만 비교해요: `dinosaur, path, fog, T. rex, mud, butterfly` = `dinosaur path fog trex mud butterfly`.

## 6구역 바뀐 것 찾기

6구역은 **읽기 → 미션 → 🔍 바뀐 것 찾기 → 📝 정리 → 🔑 열쇠** 순서예요. 나비 효과 설명은 반전이 들통나지 않도록 활동이 끝난 뒤에 나와요.

- ① 카드 6장 중 달라지거나 새로 발견한 것 3가지 고르기 (간판 철자, 대통령, 신발의 나비)
- ② 원인 → 결과 연결하기 (원인: 나비 / 결과: 간판, 대통령)
- 틀리면 오답 대기 시간이 걸려요. 끝나면 완성된 화살표, 🦋 나비 효과 문장, 📚 원작 이야기(Keith/Deutscher 선거)가 나와요. 나비 효과와 원작 이야기는 마무리 화면에도 다시 나와요.
- 교사 화면 **모둠 현황** 탭에서 켜기/끄기를 골라요 (기본: 켜기). 문구는 `Code.gs`의 `CHANGES`, `BUTTERFLY_NOTE`에서 고쳐요.

## 정리 단계 설정

- 교사 화면 **모둠 현황** 탭의 **📝 정리 단계**에서 켜기/끄기를 골라요 (기본: 켜기). 정리 중에 끄면 그 모둠은 바로 다음 구역으로 넘어가요.
- 요약 문장·단어 카드·O/X 문제(구역마다 6개)는 `Code.gs`의 `REVIEW`에 있어요. 고치고 싶으면 거기서 바꾸고 새 버전으로 배포해요.
- 모둠 현황에 "📝 정리 1인 1문제 2/4"처럼 진행 상황이 보이고,
  **📋 모둠 기록**에서 모둠원별 1인 1문제 정답/오답 수와 누가 어떤 문제를 어떻게 답했는지 볼 수 있어요.

## 소리 내어 읽기 설정

- 교사 화면 **모둠 현황** 탭에서 방식을 골라요.
  - **🎙 녹음 인증** (기본): 녹음 파일이 구글 드라이브 `타임머신 수리 미션 녹음/모둠코드/` 폴더에 `S3-02_민수.webm`처럼 저장돼요.
  - **👂 확인 버튼**: 녹음 없이, 읽은 사람이 아닌 다른 모둠원이 들어 보고 "다 읽었어요"를 눌러요 (문장 길이만큼 기다려야 눌려요).
  - **끄기**: 읽기 단계 없이 바로 미션.
- **⚠️ 수업 전에 꼭 확인**: 학생 기기로 실제 배포 주소에 들어가 녹음 버튼을 한 번 눌러 보세요.
  처음에 마이크 권한을 물으면 **허용**. 기기·학교 정책 때문에 마이크가 막히면 **확인 버튼** 방식으로 바꿔서 쓰면 돼요.
- 본문은 6개 스테이션 합쳐 **60문장**이에요. 한 문장에 15~20초쯤 걸리니 읽기만 15~20분 정도 잡아 주세요.
  줄이고 싶으면 **📄 읽기 문장** 탭에서 문장을 합치거나 빼면 돼요 (한 줄 = 한 사람이 읽는 단위).
- 녹음은 **📋 모둠 기록** 탭에서 스테이션·문장별로 누가 몇 초 읽었는지 보고 ▶로 바로 들을 수 있어요.

## 교사 대시보드 (`?page=teacher`)

- **모둠 현황**: 모둠별 모둠원, 현재 스테이션(●), 상태(📖 읽기 3/8 / 진행 중 / ⏳대기 / 🔒잠금 / 🏁탈출), 오답 수, 소요 시간. 5초마다 새로고침돼요.
- **📋 모둠 기록**: 모둠을 고르거나 모둠 현황 표에서 모둠 이름을 누르면 나와요.
  - 모둠원, 총 소요 시간, 오답 수, 시작·탈출 시각
  - 모둠원별 소리 내어 읽기: 읽은 문장 수, 녹음 길이 합계·평균
  - 스테이션별 걸린 시간, 입력한 답 전체(시각·O/X, 선생님이 열어 준 기록 포함), 문장별 녹음 듣기
- **진행 속도**: 기본은 **🚀 제한 없음 (자동 진행)** 이라 따로 조작하지 않아도 돼요. 다 같이 멈추고 싶을 때만 "3구역까지"처럼 골라요. 먼저 끝낸 모둠은 다음 구역 앞에서 기다려요.
- 모둠별 조작: ◀ 한 구역 되돌리기 · ▶ 열기(지금 구역 통과) · 🔒 잠그기/풀기 · ⏱ 대기 해제 · 🗑 삭제
- **⏸ 전체 멈춤**: 설명할 때 모든 모둠 화면을 잠가요.
- **오답 대기 시간**: 초 단위로 바꿀 수 있어요 (0이면 대기 없음).
- 스프레드시트 `Log` 시트에 모든 제출(모둠, 스테이션, 미션, 입력한 답, O/X)이 쌓여요. 수업 후 오답 분석에 쓸 수 있어요.

## 녹음이 되게 하기 (GitHub Pages, 처음 한 번)

Apps Script 화면은 구글의 틀(iframe) 안에서 열려서 **마이크가 막혀요.** 마이크를 허용해도 녹음되지 않아요.
학생 화면만 GitHub Pages에 올리면 녹음이 되고, 기록과 녹음은 지금처럼 선생님 시트와 드라이브에 저장돼요.

1. [github.com](https://github.com)에 가입하고 로그인해요.
2. 오른쪽 위 **＋ → New repository** → 이름 `time-machine`, **Public** → **Create repository**.
3. **uploading an existing file**을 눌러 `gas/Index.html`을 올려요. 올린 뒤 파일 이름을 **`index.html`**(소문자)로 바꿔요. → **Commit changes**
4. **Settings → Pages** → Branch를 **main / (root)**로 고르고 **Save**. 1~2분 뒤 위쪽에 주소가 나와요. 예: `https://아이디.github.io/time-machine/`
5. Apps Script `Code.gs` 맨 위 `STUDENT_PAGE_URL`에 그 주소를 넣어요.
6. Apps Script 배포의 액세스 권한이 **모든 사용자**인지 확인하고, **새 버전으로 배포**해요. ("학교 도메인 사용자"면 바깥 화면이 연결되지 않아요.)
7. 교사 화면의 **학생 주소 (녹음용)**을 복사해 학생에게 줘요. `…github.io/time-machine/?api=…` 모양이에요.

- 학생 화면(`Index.html`)을 고치면 GitHub의 `index.html`도 새로 올려야 해요. `Code.gs`·`Teacher.html`만 고친 경우는 Apps Script만 다시 배포하면 돼요.
- 다른 선생님은 GitHub 설정 없이 같은 `STUDENT_PAGE_URL`을 그대로 쓰면 돼요. 주소 끝의 `?api=`가 각자의 앱을 가리켜요.
- 처음 녹음할 때 크롬이 마이크 권한을 물으면 **허용**. 이미 막았다면 주소창 왼쪽 아이콘 → 권한 → 마이크 허용.

## 다른 선생님과 공유하기

주소 하나를 같이 쓰지 말고, 선생님마다 **사본**을 만들어 각자 배포해요. 그래야 학생 기록과 녹음이 선생님별로 나뉘어요.

1. 수업에 쓰는 시트와 별개로 **공유용 새 스프레드시트**를 만들어요. 이름 예: `[사본용] 타임머신 수리 미션`
2. 세 파일을 붙여 넣고, `TEACHER_PASSWORD`를 내 비밀번호가 아닌 **공유용 임시 비밀번호**로 바꿔요.
3. 학생 기록이 없는 상태인지 확인하고, 공유 설정을 "링크가 있는 사용자 · 뷰어"로 해요.
4. 시트 주소 끝의 `/edit...`을 `/copy`로 바꾼 링크를 공유해요.

받는 선생님이 할 일: 링크로 사본 만들기 → Apps Script에서 비밀번호 바꾸기 → `setup` 실행 → 웹 앱으로 새 배포 → 학생 기기로 녹음 시험.

- 학생 이름과 음성이 담기므로, 녹음 안내와 보관·삭제는 각 학교 기준을 따라 주세요. 수업이 끝나면 드라이브의 녹음 폴더를 정리해요.
- `Code.gs`에 교과서 본문이 들어 있으니, 공개 게시판이 아니라 같은 교과서를 쓰는 선생님께 링크로 전달해요.
